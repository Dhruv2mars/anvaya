# Anvaya — Privacy Policy

**Last updated:** 11 July 2026

Anvaya (“the App”) is a local-first personal Panchang and daily ratings app.

## Data we store

All core data is stored **on your device** in a local SQLite database:

- Personal metrics (names you create)
- Daily ratings (1–5)
- Optional one-line notes
- Cached Panchang fields for days you open
- Optional cached GPS coordinates for Panchang accuracy

We do **not** require an account. We do **not** operate a cloud backend for core features in this version. We do **not** sell personal data.

## Location

If you grant location permission, the App uses approximate coordinates to compute local sunrise and Hindu Panchang (Tithi, Vaar, Paksha, and related fields). Location is used only for astronomy calculations and may be cached on-device. You may deny permission; the App falls back to a default location (Delhi) with reduced local accuracy.

## Children

The App is not directed at children under 13.

For privacy questions about this open-source / self-published build, contact the publisher listed on the store listing.

## Changes

We may update this policy when features change (for example if optional backup/sync is added later). Material changes will be noted by updating the date above.
